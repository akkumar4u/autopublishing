# Auto Publishing Workflow

AI assisted content publishing system that imports content from Google Docs, prepares SEO metadata, and creates WordPress drafts automatically.

## Features

- Import Google Docs content
- Extract:
  - Title
  - Meta title
  - Meta description
  - Keywords
  - Slug
  - Image shortcode
  - CTA buttons
- Clean HTML generation
- WordPress draft creation
- SEO validation dashboard
- React publishing interface

---

# Tech Stack

## Frontend

- React
- Vite
- Lucide Icons
- CSS

## Backend

- Node.js
- Express
- Cheerio
- WordPress REST API
